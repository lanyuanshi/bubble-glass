# Frost Evening Verse（霜晚辞）

exteraless / exteraGram 的 Python 插件（Chaquopy）：给聊天气泡、主页、联系人页、设置页加上「玻璃」质感——透明度、毛玻璃模糊、浓度调节，晴空/夜幕风格，以及页面独立壁纸；另带防撤回，撤回的消息保留并加标记。

## 功能

### 聊天气泡
- **风格**：跟随主题 / 晴空 / 夜幕 / 自动（白天晴空、夜间夜幕）
- **透明度** 0–100：气泡底色有多透
- **模糊** 0–25：把气泡背后的聊天壁纸做毛玻璃模糊
- **浓度** 0–100：磨砂层浓度
- **玻璃描边**：气泡边缘高光描边
- 一键预设：「晴空」「夜幕」
- 模糊层固定在壁纸上，聊天列表滚动、键盘弹出时不会跟着气泡漂移

### 页面壁纸与透明度（主页 / 联系人 / 设置，各自独立）
设置项分组收纳：主页 / 联系人 / 设置 的壁纸和透明度收在「页面壁纸与透明度」子页面里，主设置页更短。
- 每页可单独选择壁纸：关闭 / 自定义图片 / 跟随聊天壁纸
- 每页单独调透明度，作用到底色、圆角卡片、顶栏渐变、搜索框
- 支持旧版（`RecyclerListView.drawSectionsBackgrounds`）和新版（`BitmapSectionsItemDecoration`）两种卡片绘制方式

### 防撤回
- 被撤回的消息保留在聊天里，时间旁显示标记（可自定义标记文字）
- 可选是否包含机器人消息
- 基于客户端（exteraless / NagramX）的「保存已删除消息」能力实现：消息内容保留，时间旁显示标记

### 内容保护（允许截图和下载）
- 在开启「禁止截图和转发」的群组/频道里，也能截图、保存媒体
- 通过让 `MessagesController.isChatNoForwards` / `isUserNoForwards` 在开启时返回 false 来解除 `FLAG_SECURE` 和保存限制
- 只影响本机显示与保存；转发仍受服务端限制，秘密聊天不受影响

## 安装

1. 在 exteraless 中打开 `bubble_glass.plugin` 安装（首次会要求授予 **hooks** 钩子权限；壁纸功能还需要 **intents**、**files** 权限）
2. 安装后**彻底关闭 app 再打开**一次（exteraless 是启动后才加载插件，已经打开的页面需要重建才能生效）
3. 在插件设置里调整各项参数

## 兼容性

- 主要针对 exteraless 13.x（beta15 及之后）开发
- 缺失的类/方法会自动跳过并记日志，不会导致安装失败
- 防撤回依赖客户端内置的「保存已删除消息」能力；标记显示在消息时间旁
- 插件日志标签：`plugin.bubble_glass`

## 开发

插件是单个 Python 文件（`bubble_glass.plugin`），直接用 Python 语法编写，无需打包。修改后把文件推送到设备并清理 `__pycache__`、重启 app 即可生效。

```bash
python3 -m py_compile bubble_glass.plugin
```
